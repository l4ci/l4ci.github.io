Work across tasks and accounts

Start a round in Claude Code or Codex. That session assigns issues to workers, follows their progress and handles the merges. Workers can use Claude Code, Codex or OpenCode.

Use several accounts to spread the work. When an agent needs a product decision, it comes back to you. Account and worker setup

Start in your coding agent

Install rota, then open your project in your agent. Init helps configure it; orchestrate starts the round.

/rota-init
Set up this project
/rota-orchestrate
Choose issues and start

In Codex, use $rota-init and $rota-orchestrate. Separate worker sessions use herdr or tmux.

Follow the first-round guide

Check changes before merging

The merge gate checks required reviews and runs your configured tests on the PR combined with the current base. Failed checks send the work back. Repeated failures can pause an issue for your help.

What the gate catches depends on your tests and configuration. Read about the safeguards and their limits.
