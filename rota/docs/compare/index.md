Each page puts rota beside one other tool: what each is for, a side-by-side table, where the other tool is stronger, and where rota is. Every page names the release or commit it was checked against, and the date.

**Workflows and skills** for one agent at a time:

- [GSD](/rota/docs/compare/gsd/): spec-driven phases from discuss to ship
- [Superpowers](/rota/docs/compare/superpowers/): a skills methodology for many harnesses
- [OpenSpec](/rota/docs/compare/openspec/): living specs and delta change folders
- [ralph](/rota/docs/compare/ralph/): a fresh-context loop over a `prd.json`

**Parallel agents** in worktrees:

- [Conductor](/rota/docs/compare/conductor/): a Mac app for agents in workspaces
- [Orca](/rota/docs/compare/orca/): a desktop app for fleets of agents
- [Vibe Kanban](/rota/docs/compare/vibe-kanban/): a kanban board that runs agents
- [Claude Squad](/rota/docs/compare/claude-squad/): a TUI for agents in tmux sessions

**Orchestrators** with a coordinating agent:

- [Gas Town](/rota/docs/compare/gastown/): a Mayor, polecats and a merge queue
- [Octo](/rota/docs/compare/octo/): several AI providers on one question

**No tool at all:**

- [A bare Claude Code session](/rota/docs/usage/rota-vs-plain-session/) that runs its own subagents
